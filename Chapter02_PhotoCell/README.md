# Chapter 2 – Photocell

Files for Chapter 2 of the book *App Inventor & ESP32*.

## Arduino sketches

| Sketch | Description |
|---|---|
| [`PhotoCell`](arduino/PhotoCell/) | Part 1: the photoresistor turns the LED on when it is dark |
| [`PhotoCellBlue`](arduino/PhotoCellBlue/) | Part 2: light reading from the app over Bluetooth Classic |

**Board**: ESP32 Dev Module (ESP32-WROOM-32)

## Arduino libraries

All the libraries used come with the ESP32 board package: nothing to install.

## App Inventor

- [`PhotoCell.aia`](app-inventor/PhotoCell.aia)

To import it: on [ai2.appinventor.mit.edu](https://ai2.appinventor.mit.edu) choose **Projects → Import project (.aia) from my computer**.
