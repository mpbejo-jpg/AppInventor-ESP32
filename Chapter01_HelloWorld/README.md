# Chapter 1 – Hello World

Files for Chapter 1 of the book *App Inventor & ESP32*.

## Arduino sketches

| Sketch | Description |
|---|---|
| [`HelloWorld`](arduino/HelloWorld/) | Part 1: the push-button turns the LED on |
| [`HelloWorldBlue`](arduino/HelloWorldBlue/) | Part 2: LED control from the app over Bluetooth Classic |

**Board**: ESP32 Dev Module (ESP32-WROOM-32)

## Arduino libraries

All the libraries used come with the ESP32 board package: nothing to install.

## App Inventor

- [`HelloWorld.aia`](app-inventor/HelloWorld.aia)

To import it: on [ai2.appinventor.mit.edu](https://ai2.appinventor.mit.edu) choose **Projects → Import project (.aia) from my computer**.
