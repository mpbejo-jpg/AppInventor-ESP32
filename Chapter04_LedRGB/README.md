# Chapter 4 – RGB LED

Files for Chapter 4 of the book *App Inventor & ESP32*.

## Arduino sketches

| Sketch | Description |
|---|---|
| [`LedRGB`](arduino/LedRGB/) | Part 1: color selected with the buttons, brightness with the potentiometer |
| [`LedRGBBlue`](arduino/LedRGBBlue/) | Part 2: RGB LED control from the app over Bluetooth Classic |

**Board**: ESP32 Dev Module (ESP32-WROOM-32)

## Arduino libraries

All the libraries used come with the ESP32 board package: nothing to install.

## App Inventor

- [`LedRGB.aia`](app-inventor/LedRGB.aia)

To import it: on [ai2.appinventor.mit.edu](https://ai2.appinventor.mit.edu) choose **Projects → Import project (.aia) from my computer**.
