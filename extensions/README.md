# App Inventor extensions

The extensions used in the book are already included in the `.aia` projects of each chapter. You only need the files below if you want to add an extension to a new project (in the Designer: **Extension → Import extension**).

## Extensions by the author

| Extension | Used in |
|---|---|
| [`MifareInfo`](MifareInfo/) | Chapters 15, 16 |
| [`OpenWeatherMap`](OpenWeatherMap/) | Chapter 11 |
| [`FirebaseManager`](FirebaseManager/) | Chapters 16, 18 |
| [`Pushy`](Pushy/) | Chapter 19 |
| [`AudioStreamExt`](AudioStreamExt/) | Chapter 19 |
| [`WebSocketExt`](WebSocketExt/) | Chapter 19 |
