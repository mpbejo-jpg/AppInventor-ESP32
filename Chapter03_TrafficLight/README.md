# Chapter 3 – Traffic Light

Files for Chapter 3 of the book *App Inventor & ESP32*.

## Arduino sketches

| Sketch | Description |
|---|---|
| [`TrafficLight`](arduino/TrafficLight/) | Part 1: traffic light with pedestrian button |
| [`TrafficLightBlue`](arduino/TrafficLightBlue/) | Part 2: traffic light controlled from the app over Bluetooth Classic |

**Board**: ESP32 Dev Module (ESP32-WROOM-32)

## Arduino libraries

All the libraries used come with the ESP32 board package: nothing to install.

## App Inventor

- [`TrafficLight.aia`](app-inventor/TrafficLight.aia)

To import it: on [ai2.appinventor.mit.edu](https://ai2.appinventor.mit.edu) choose **Projects → Import project (.aia) from my computer**.
